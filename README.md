# Ecommerce Sales Dashboard – Power BI

Interactive Ecommerce Sales Dashboard built using Power BI and CSV datasets.

## Features

* Sales & Profit Analysis
* State-wise and Customer-wise Insights
* Category Performance Analysis
* Payment Mode Analysis
* KPI Tracking (Sales, Profit, Quantity, AOV)

## Tools Used

* Power BI
* Power Query
* DAX
* CSV Data

## Skills Applied

* Data Cleaning & Transformation
* Data Modeling & Relationships
* DAX Measures
* Interactive Dashboard Design
